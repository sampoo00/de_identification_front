# 지능형 비식별화 에이전트 시스템 (Frontend)

자연어 명령과 VLM/SAM3 AI 모델을 결합하여 자동으로 이미지 속 개인정보 및 민감 데이터를 추출하고, 안전하게 가려주는 고성능 비식별화 플랫폼입니다.

## 설치 방법

프로젝트 종속성 설치 후 실행합니다:
```bash
npm install
npm run dev
```

## 사용법

1. 사이트 접속 후 비식별화하고자 하는 이미지를 업로드합니다 (다중 이미지 가능).
2. "사람 얼굴을 가려줘" 또는 "배경만 흐리게 해줘" 등 자연어 명령어를 프롬프트에 입력합니다.
3. 시스템이 자동으로 영역을 인식하고 처리 결과를 제공하면 다운로드합니다.
4. 사용자 설정에서 외부 API 연동을 위한 전용 API 키를 발급받고 관리할 수 있습니다.

## 환경변수 목록

로컬 환경 구성을 위해 `.env` 파일에 다음 항목들을 설정해야 합니다:
```env
NEXT_PUBLIC_API_BASE_URL=
NEXT_PUBLIC_LLM_PROVIDER=
NEXT_PUBLIC_OLLAMA_BASE_URL=
```

## 기여 가이드

- 본 프로젝트는 **React + Next.js 14**, **TypeScript** 환경에서 개발됩니다.
- 모호한 타입 회피(`any` 사용)를 엄격히 금지합니다.
